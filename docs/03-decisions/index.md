# Decisions — ADR registry

The architectural invariants that protect email-2-data, one decision per ADR. This index is
the discoverability surface; read it top-to-bottom once, refer back when a change touches an
invariant. ADRs are **immutable once Accepted** — supersede with a new ADR, don't edit history
(`adr-000-template.md` is the template).

If your change touches an ADR's invariant, the ADR must hold or be explicitly superseded by a
new ADR in the same commit. A new architectural rule means a new ADR + a row here.

| [025](adr-025-attachment-guards-and-scoped-re-extraction.md) | attachment-guards-and-scoped-re-extraction | A thin project was a **crash**, not a weak model: a 283 MP attachment (1 MB vector export) passed the byte-only filter, Vertex 400'd every retry, `build_entry` swallowed it, the entities fallback made it look sparse, and the incremental gate froze it forever. Images are now guarded by **pixels** via a header-only probe (unmeasurable formats pass — dropping a readable drawing on a guess is worse); **SVG routes to text** (it is geometry, and below the image byte floor); a failed pass sets `spec_error` + a `spec_draft_failed` audit event; `rebuild_jobspecs(only=…)` re-extracts one project without re-billing the corpus; `llm.with_tier` picks light/standard/heavy **per call on a copy** (mutating shared `settings` would repoint every later call), and `thinking_budget` is no longer hardcoded to 0. | [026](adr-026-re-extraction-reads-the-whole-project.md) | re-extraction-reads-the-whole-project | "Reprocessar" re-reads **everything the project knows**, not just its emails: the ADR-025 email pass plus a new pass over the ADR-015 timeline events (Registar notes, decisions, calls, WhatsApp), at one chosen **cost** tier. Events run oldest→newest **after** the messages, so a written-down note beats a passively-parsed email. A field read out of a note is written as `source_mid="event:<rowid>"` with **no** channel/asserted_by — a fifth case in the ADR-022 §7 vocabulary, on the *machine* side: attributing it to the note's author would freeze a model guess inside `human_touched_fields` and render it as a FACT nobody confirmed. ADR-025's three safety properties hold unchanged (human decisions skipped, nothing deleted, identical values no-op → idempotent). A note the model could not read is reported (`events.failed`), never swallowed — hence `extract_fields_strict` beside the capture path's degrading wrapper. Cost is stated before the click and split `read` vs `applied` after; blank notes never reach the model; a project with only notes and no emails is now serviceable. Registar's placeholder narrows from "sem IA" to "a IA só lê isto se pedires Reprocessar" — the storage is still verbatim, but the blanket promise was no longer true. |
